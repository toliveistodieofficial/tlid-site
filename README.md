## About

**To Live Is To Die — TLITD** is an action dark fantasy game set in a world shaped by **Vésper**, a power capable of manifesting extraordinary abilities known as Dádivas.

This repository contains the source code for the official **To Live Is To Die** website.

The website serves as the central hub for the project, bringing together information about the game, its universe, characters, official Wiki and, in the future, direct access to the game.

---

## Website

The official website currently includes:

- Game presentation
- TLITD universe
- Character database
- Official Wiki
- Vésper information
- User account system
- Game store structure
- Supabase authentication

More sections will be added as development progresses.
